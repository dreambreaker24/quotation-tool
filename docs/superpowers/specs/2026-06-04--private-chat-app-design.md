# 私密通訊 App 規格文件

**日期：** 2026-06-04
**專案代號：** secret-chat
**類型：** 全新獨立專案

---

## 一、專案目標

建立一個高隱蔽性的 2 人私密通訊 PWA，外觀偽裝成計算機 app（名稱「記帳本」），輸入密碼後進入真實的聊天介面，支援文字、圖片、影片、共享行事曆，所有內容端對端加密。

---

## 二、平台與技術棧

| 項目 | 選擇 |
|------|------|
| 平台 | PWA（iOS Safari、Mac Chrome/Safari、Windows Chrome/Edge） |
| 前端 | React + Vite |
| 後端 | Firebase（Firestore + Storage + Auth + Hosting） |
| 加密 | AES-256-GCM，PBKDF2 衍生金鑰 |
| 部署 | Firebase Hosting（免費方案） |

**不需要 App Store，存到 iOS 主畫面即可使用。**

---

## 三、偽裝層與解鎖

### 3.1 外觀
- PWA 名稱：**記帳本**
- 圖示：帳本風格中性設計（非計算機圖示，避免被聯想）
- 打開 app：顯示 iOS 風格深色計算機介面

### 3.2 解鎖流程
```
打開 app → 計算機畫面
    → 使用者輸入密碼數字 → 按 =
    → 正確：背景執行 Firebase 登入 → 切換至聊天主畫面
    → 錯誤：顯示 Error，3 秒後清零，不給任何提示
    → 連續錯誤 5 次：鎖定 5 分鐘
```

### 3.3 退出
- 聊天介面右上角設一個低調的退出按鈕（例如長按標題列）
- 點擊後立刻切回計算機畫面，清除記憶體中的解密金鑰

---

## 四、帳號系統

- 使用 Firebase Anonymous Auth + 自訂 UID 綁定
- 不需要填寫 email 或任何個人資料
- 兩組帳號由管理員（柏）預先建立，各自對應一組密碼
- 密碼同時作為 Firebase 登入憑證與加密金鑰來源

---

## 五、聊天功能

### 5.1 訊息類型
| 類型 | 說明 |
|------|------|
| 文字 | 一般文字訊息 |
| 連結 | 自動偵測 URL，藍字顯示，點擊開新分頁跳轉 |
| 圖片 | 點擊放大，長按儲存至裝置 |
| 影片 | 內嵌播放，支援下載 |

### 5.2 訊息狀態
- ✓：Firebase 已收到
- ✓✓：對方已讀

### 5.3 訊息搜尋
- 輸入關鍵字 → 裝置端解密後比對全部訊息
- 顯示符合結果清單（含時間）
- 點擊結果 → 跳到對話中該則訊息，黃色高亮標記

### 5.4 訊息持久性
- 所有訊息存於 Firebase Firestore，關閉 app 不遺失
- 無訊息數量上限（受 Firebase 免費配額限制，初期足夠）

## 六、行事曆

### 6.1 共享行事曆
- 兩人都能新增、編輯、刪除事件
- 事件欄位：日期、時間（可選）、標題、備註
- 月曆視圖：有事件的日期顯示橘色圓點

### 6.2 提醒方式

- 進入 app 時，若當天或明天有事件，頂部出現提醒橫幅

## 七、加密機制

### 7.1 架構
```
使用者輸入內容
    → AES-256-GCM 加密（裝置端）
    → 密文送至 Firebase（Firebase 只看到亂碼）
    → 對方接收密文 → 裝置端解密 → 顯示內容
```

### 7.2 金鑰衍生
- 雙方事先約定一個**共享密語**（與登入密碼分開）
- 使用 PBKDF2（SHA-256，100,000 次迭代）將密語轉為 256-bit 金鑰
- 金鑰只存在裝置記憶體中，app 關閉即清除

### 7.3 加密範圍
| 資料 | 是否加密 |
|------|---------|
| 文字訊息 | ✅ |
| 圖片／影片 URL | ✅ |
| 圖片／影片檔案本體 | ✅（上傳前在裝置端加密，再存到 Storage） |
| 行事曆事件 | ✅ |
| 訊息時間戳記 | ❌（Firestore 需要排序） |
| 已讀狀態 | ❌ |

### 7.4 安全說明
- Firebase 被駭或帳號外洩：駭客只看到密文，無法解讀
- 遺失共享密語：**無法恢復**歷史訊息（這是 E2E 加密的必然代價）

---

## 八、通知設定

- **零通知策略**：不發任何系統推播或鎖定畫面通知
- 新訊息、行事曆提醒一律只在 app 內顯示
- app 內未讀訊息：聊天列表顯示未讀數字標記

---

## 九、資料模型（Firestore）

```
/users/{userId}
  - createdAt

/messages/{messageId}
  - senderId
  - encryptedContent   // AES 密文
  - type               // text | image | video
  - timestamp
  - readBy: []

/calendar/{eventId}
  - encryptedContent   // AES 密文（含標題、時間、備註）
  - createdBy
  - timestamp
```

9. 行事曆（共享）
