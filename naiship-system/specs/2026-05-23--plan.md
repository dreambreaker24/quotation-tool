### Task 8: 複製案件後自動跳轉選取

**Files:**
- Modify: `naiship-system/src/components/cases/GanttTab.vue:260-278`

現狀：`copyCase()` 會開啟新案件的 `CaseEditModal`（`editingCaseId.value = docRef.id`），但關閉 Modal 後 Gantt 仍停在原案件，使用者需手動找到並展開新案件。

目標：複製後除了開啟 edit modal 外，同時將新案件設為已選取並展開，這樣關閉 Modal 後 Gantt 會直接顯示新案件的工種/收款等區塊。

- [ ] **Step 1: 修改 `copyCase` 函數，複製後自動選取新案件**

修改 `GanttTab.vue` 的 `copyCase` 函數（第 260-278 行）：

```js
async function copyCase() {
    const c = casesStore.cases.find(x => x.id === selectedCaseId.value)
    if (!c) return
    const workTypes = (c.workTypes ?? []).map(wt => ({
        ...wt,
        id: Date.now().toString(36) + Math.random().toString(36).slice(2)
    }))
    const docRef = await casesStore.addCase({
        name: `${c.name}（複製）`,
        companyId: c.companyId,
        status: 'negotiating',
        assignees: c.assignees ?? [],
        assigneeName: c.assigneeName ?? '',
        assignedTo: c.assignedTo ?? '',
        address: c.address ?? '',
        estimatedAmount: 0,
        signedAmount: 0,
        workTypes,
    })
    toast('案件已複製，請補充資料')
    if (docRef?.id) {
        const newId = docRef.id
        // 收合原案件，展開新案件
        if (selectedCaseId.value && selectedCaseId.value !== newId) {
            expanded[selectedCaseId.value] = false
        }
        expanded[newId] = true
        selectedCaseId.value = newId
        selectedCaseName.value = `${c.name}（複製）`
        expandedCaseId.value = newId
        expandedCaseName.value = `${c.name}（複製）`
        tasksStore.subscribe(newId)
        editingCaseId.value = newId
    }
}
```
