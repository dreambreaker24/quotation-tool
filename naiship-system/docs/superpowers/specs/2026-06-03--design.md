## 1. 通知系統

### Firestore 結構

```
notifications/{id}
  userId      : string   // 接收者 UID
  actorName   : string   // 操作者姓名，例如「柏」
  message     : string   // 動作描述，例如「更新了 楠梓/遠見禾悅」
  caseId      : string   // 相關案件 ID（用於跳轉）
  caseName    : string   // 案件名稱（顯示用）
  createdAt   : Timestamp
```

### 觸發時機

| 事件 | 觸發位置 | 通知對象 |
|------|---------|---------|
| 新增案件 | `casesStore.addCase` 成功後 | 全公司所有 user，排除操作者本人 |
| 儲存案件 | `casesStore.updateCase` 成功後 | 全公司所有 user，排除操作者本人 |
| 新增公司佈達 | `AnnouncementTab.vue` 儲存成功後 | 全公司所有 user，排除操作者本人 |

通知寫入：`notificationsStore.notifyAll(actorName, message, caseId, caseName)` 批次 `addDoc` 寫給每位 user（排除自己），每次觸發約 5–6 筆。用 `usersStore.users` 取得所有 UID。

**觸發位置（在元件儲存完後呼叫，非在 store 內部）**
- `CasesView.vue` submitCase → 新增案件
- `CaseEditModal.vue` save → 儲存案件資料
- `WorkTypePanel.vue` 新增/編輯工種
- `PaymentMilestones.vue` 新增/編輯收款里程碑
- `CaseTasks.vue` 新增/完成待辦
- `CaseReview.vue` 新增/編輯檢討
- `PhotoUpload.vue` 上傳照片完成
- `AnnouncementTab.vue` 新增公司佈達

### NavBar 鈴鐺

- `NotificationBell.vue` 獨立元件，嵌入 `NavBar.vue` 右側
- real-time `onSnapshot` 監聽 `notifications` where `userId == 當前 UID`
- 未讀數 > 0 → 鈴鐺右上角紅色 badge 顯示數字
- 點鈴鐺 → dropdown 展開，列出所有通知（最新在上）
- 每筆顯示：「**{actorName}** {message}」+ 時間
- 點任一筆 → 導向 `/cases?caseId={caseId}` → 刪除該筆通知 → dropdown 關閉
- 點鈴鐺外部區域 → dropdown 關閉

### Firestore Rules

```
match /notifications/{notifId} {
  allow read, delete: if isSignedIn() && resource.data.userId == request.auth.uid;
  allow create: if isSignedIn();
}
```

### 新增檔案

- `src/components/layout/NotificationBell.vue`
- `src/stores/notifications.js`

### 修改檔案

- `src/components/layout/NavBar.vue`：引入 `NotificationBell`
- `src/stores/cases.js`：`addCase` / `updateCase` 後呼叫通知寫入
- `firestore.rules`：新增 notifications 規則

## 2. 公司佈達 Tab

### Firestore 結構

```
announcements/{id}
  title          : string
  content        : string
  images         : string[]   // Cloudinary URL 陣列
  createdBy      : string     // UID
  createdByName  : string     // 顯示名稱
  createdAt      : Timestamp
  updatedAt      : Timestamp
```

### 版面設計

**置頂最新公告（大顯示）**
- 標題（加粗大字）
- 內容（完整顯示）
- 圖片（橫向捲動或格狀）
- 日期 + 發布人
- 主管：編輯 / 刪除 按鈕

**舊公告清單**
- 每筆：標題 + 日期 + 發布人 + 點擊展開內容
- 主管：每筆有刪除按鈕

### Tab 未讀紅點

- `localStorage` 記錄 `announcementLastRead` 時間戳
- 進入公司佈達 Tab 時更新 `announcementLastRead = now`
- NavBar 計算：最新公告 `createdAt > announcementLastRead` → 公司佈達 Tab 顯示紅點

### 權限

- 新增 / 編輯 / 刪除：`isManager` 才顯示操作按鈕
- 讀取：所有登入用戶

### 圖片上傳

複用現有 `uploadPhoto(file, 'announcement')` from `useStorage.js`

### Firestore Rules

```
match /announcements/{id} {
  allow read: if isSignedIn();
  allow create, update: if isManager();
  allow delete: if isManager();
}
```

### 新增檔案

- `src/components/cases/AnnouncementTab.vue`

### 修改檔案

- `src/views/CasesView.vue`：新增第四個 Tab + 紅點邏輯
- `firestore.rules`：新增 announcements 規則

## 3. 工作日誌手機版響應式

### 問題點

`WorkJournalTab.vue` 目前週檢視使用橫向表格、表單欄位窄、觸控目標小。

### 調整項目

| 項目 | 桌面版 | 手機版（< lg） |
|------|--------|---------------|
| 員工選擇 | 左側 200px 固定欄 | 置頂 select（已有，優化樣式） |
| 週檢視 | 橫向表格 | 單日卡片垂直捲動 |
| 單日檢視 | 正常 | 欄位全寬堆疊 |
| 填寫表單 | 彈出 Modal | 全屏 Modal，輸入欄全寬 |
| 按鈕 | 正常 | padding 加大，min-height 44px |
| 油資/加班申請 | 內嵌區塊 | 獨立折疊展開 |

### 原則

- 使用現有 Tailwind `sm:` / `lg:` 響應式前綴
- 不建立獨立手機元件，在現有 template 加 class 控制
